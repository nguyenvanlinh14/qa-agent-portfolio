AI agents are part of the pipeline, not a gimmick

Every layer of this repo was planned, generated, reviewed or triaged by an agent — with a human gate at each step.

Plan

Claude Code + Playwright MCP explores the app in a real browser and writes a Markdown test plan.

Generate

A test-generator sub-agent turns the plan into POM-based specs that follow CLAUDE.md rules.

Review

I review the diff. @claude in a PR runs a second review against the project checklist.

Heal

When UI changes, the test-healer agent re-inspects the DOM and proposes locator fixes — never weaker assertions.

Triage

On red CI, ai-triage.mjs sends failures to Claude and writes a root-cause summary to the job summary.
