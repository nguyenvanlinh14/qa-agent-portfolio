# grafana/k6#4260 — deriveBits: support lengths that are not multiples of 8

Trạng thái: **đã bình luận trên issue (2026-10-27), chờ maintainer phản hồi** (chưa fork, chưa mở PR).
Issue: https://github.com/grafana/k6/issues/4260

## Hiện trạng trên `main` của k6

- `internal/js/modules/k6/webcrypto/subtle_crypto.go` từ chối mọi `length % 8 != 0` ("currently only multiples of 8 are supported").
- `elliptic_curve.go` (ECDH + X25519) trả về `b[:length/8]`.
- Hai test WPT `8*size - 11` bị tắt bằng patch trong `tests/wpt-patches/` (TODO trỏ tới xk6-webcrypto#80).
- Phát hiện thêm: `length` âm và chia hết cho 8 (vd `-8`) làm `b[:-1]` **panic** (slice bounds out of range).

## Bản nháp (`k6-4260-derivebits.patch`, +157/−70)

- `truncateToBits(secret, length)`: lấy `ceil(length/8)` byte đầu, xoá các bit thừa của byte cuối; `length < 0` hoặc lớn hơn độ dài secret → `OperationError`.
- Bỏ kiểm tra `%8` toàn cục; PBKDF2 giữ kiểm tra riêng của nó.
- Test mới `tests/derive_bits_test.go`: P-256/384/521 + X25519 với độ dài 1, 7, 9, bits−11, bits−1; các ca lỗi (0, âm, bits+1, PBKDF2 12 bit). 15/15 pass; trên code cũ test này bắt được panic.
- Xoá hai patch WPT để test upstream chạy lại.

Đã chạy: `go test ./internal/js/modules/k6/webcrypto/...` (pass), `go vet`, `gofmt`.
Chưa chạy: bộ WPT thật (`tests/checkout.sh` cần tải web-platform-tests), `golangci-lint`.

Câu hỏi mở: hỗ trợ `length: null` (trả toàn bộ secret) cần đổi kiểu tham số sang `sobek.Value` — làm chung hay PR riêng?
